# Isomorphic animation source

Current version: 6, including solid thinning and retraction of disconnecting bridges.

## Preview the included animation

Run from this folder:

```sh
python3 -m http.server 8768 --bind 127.0.0.1 --directory site
```

Open http://127.0.0.1:8768/animation.html in your browser. The included player and rendered assets are ready to use; Python is all you need for this preview.

## Rebuild from source

Requirements: Python 3.14 (the version used for this export), Node.js, and FFmpeg. Node.js and FFmpeg must be on your PATH. There are no npm dependencies.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
node prepare.cjs
.venv/bin/python render.py --size 1080 --fps 60
node publish.cjs
```

`publish.cjs` writes the portable player and its assets to `site/`. Rendering creates the MP4; the included GIF is a snapshot of the current version and is not regenerated by that command.

## Main files

- `render.py`: circle/bridge rendering, solid neck retraction, holds, MP4 export.
- `choreography.py`: short smooth paths, contact constraints, shared motion clock.
- `player.html`: editable browser player template, spline overlay and playback controls.
- `prepare.cjs`: rebuild the eleven exact logo stages from `favorites.json`.
- `circular-geometry.js`: tangent-circle logo geometry and generator.
- `route-cache-v5.json`: current optimized paths, used by version 6 as well.
- `route-cache-v4.json`: earlier routes retained only for the travel-reduction verification.
- `shorten.py`: refine selected paths (zero-based transition indices).
- `animation.json`: prepared shape geometry and timing (2-second holds, 2.4-second transitions).
- `assets/`: current MP4, GIF, stage SVGs/PNGs and spline data.
- `site/`: ready-to-serve animation and favorites view.

## Verify geometry and motion

```sh
.venv/bin/python verify_motion.py
.venv/bin/python verify_retraction.py
```

The checks cover circle and bridge clearance, contact only for connecting, complete retraction, opaque interiors and still holds. Source and required data are bundled here; the original repository is not needed.
